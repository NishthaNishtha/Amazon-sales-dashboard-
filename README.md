# Amazon Sales Dashboard 📊

## 🔍 Project Overview

This project presents an interactive Amazon Sales Dashboard built using Power BI to analyze sales performance, profit trends, and customer behavior across different regions and categories.

The dashboard helps in deriving meaningful business insights and supports data-driven decision making.

---

## 🎯 Objectives

* Analyze overall sales and profit performance
* Identify top-performing products and categories
* Track monthly and regional sales trends
* Understand customer segment contribution

---

## 🛠 Tools & Technologies

* Power BI
* Microsoft Excel

---

## 📊 Key KPIs

* Total Sales
* Total Orders
* Total Profit
* Profit Margin (%)

---

## 📈 Dashboard Insights

* Sales distribution across regions and categories
* Monthly sales trend analysis
* Top-performing products
* Customer segment analysis
* Profitability insights
